Ibtidai is an AI-driven learning studio for self-directed, long-term skill building. The platform takes a broad learning goal, decomposes it into a structured sequence of focused lectures, and dynamically adapts the learning path based on the learner's interests and observed progress.

Key features include:

- **Dynamic curriculum planning** — learning goals are automatically broken down into smaller, linked lecture units with a coherent progression
- **Adaptive learning paths** — the next topic is selected based on demonstrated mastery, identified weak areas, and learner preferences
- **Spaced repetition** — targeted question sessions and concept-level mastery tracking schedule review of weak areas over time
- **Knowledge graph** — a visual concept map showing how learned topics relate and where gaps remain
- **Source-grounded lectures** — content is generated with web grounding and source links are included for verification and deeper exploration
- **Bring-your-own-model** — works with OpenAI, Anthropic (Claude), Google Gemini, and Groq; users supply their own API key for full cost control

The platform is particularly well-suited for technical fields that lack a clean off-the-shelf curriculum, such as game development, machine learning engineering, electronics, and applied mathematics.
